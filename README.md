# 💰 Personal Financial Tracker

A full-stack WPF application designed for tracking personal income and expenses, built with C#, ASP.NET Core Web API, MVVM architecture, and SQL database support. 

---

## 📌 Features

### ✅ Desktop (WPF) Client
- 🔐 **User Authentication** – JWT-based login system with secure token storage.
- 📊 **Transaction Management** – Add, view, and delete income and expense records.
- 🧮 **Categorized Tracking** – Track by category, date, and description.
- 🔄 **Real-Time Sync** – Synchronizes with remote ASP.NET Core Web API.
- 🧱 **MVVM Architecture** – Clean separation of UI and logic for maintainability.

### ☁️ ASP.NET Core Web API
- 🔐 **User Registration & Login**
- 📁 **CRUD Operations** for financial transactions
- 🧾 **DTO Mapping** for API decoupling
- 🔗 **EF Core with SQL Server** – Entity relationships and migrations

---

## 🧰 Tech Stack

| Layer          | Technology                                      |
|----------------|--------------------------------------------------|
| Frontend       | WPF (.NET 8), MVVM Pattern                       |
| Backend        | ASP.NET Core Web API                             |
| Authentication | JWT (JSON Web Tokens)                            |
| Database       | SQL Server / SQLite / LiteDB (optional local DB) |
| Data Access    | Entity Framework Core                            |
| Tools          | Visual Studio, Postman, Swagger, Git             |
